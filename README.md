# Taiwan 2027

A shared, read-only itinerary and budget for January 23 to February 2, 2027.

- [Daily itinerary](https://ivyjoycedegracia-pixel.github.io/taiwan-2027/taiwan-2027-itinerary.html)
- [Per-person budget](https://ivyjoycedegracia-pixel.github.io/taiwan-2027/taiwan-2027-budget.html)

The site uses two standalone HTML pages, hosted by GitHub Pages from the main branch. No login is required. Budget choices are local to each visitor and passed between pages in the navigation links; they do not update anyone else's copy. Prices and journey times are planning estimates.

To update, replace the two HTML pages together and use the repository PR workflow. The original local project keeps the generation inputs and verification notes.
